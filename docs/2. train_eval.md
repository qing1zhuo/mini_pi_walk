## 二、训练与评测

以下为无头服务器用命令
### 1. 训练
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.train \
  --task=pai_ppo \
  --experiment_name=baseline \
  --run_name=v1 \
  --headless \
  --num_envs=2048 \
  --sim_device=cuda:0 \
  --rl_device=cuda:0 \
  --graphics_device_id=-1 \
  --max_iterations=10001
```

若要续训
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.train \
  --task pai_ppo \
  --experiment_name baseline \
  --resume \
  --load_run Oct31_00-29-08_v1 \
  --checkpoint 10001 \
  --max_iterations 2000 \
  --num_envs 2048 \
  --run_name v1 \
  --headless
```

### 2. 评测与导出
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.play \
  --task pai_ppo \
  --experiment_name baseline \
  --load_run Oct31_00-29-08_v1 \
  --checkpoint -1 \
  --num_envs 64 \
  --headless \
  --rl_device cuda:0 \
  --sim_device cuda:0
```

### 3. sim2sim测评
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.sim2sim \
  --headless \
  --load_model logs/baseline/exported/policies/policy_torch.pt
```
