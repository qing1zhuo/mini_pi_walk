## 二、训练与评测

以下为无头服务器用命令
### 1. 训练
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.train \
  --task=pai_ppo \
  --experiment_name=baseline \
  --run_name=v1 \
  --headless \
  --num_envs=2048 \
  --sim_device=cuda:0 \
  --rl_device=cuda:0 \
  --graphics_device_id=-1 \
  --max_iterations=10001
```

若要续训
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.train \
  --task pai_ppo \
  --experiment_name baseline \
  --resume \
  --load_run Oct31_00-29-08_v1 \
  --checkpoint 10001 \
  --max_iterations 2000 \
  --num_envs 2048 \
  --run_name v1 \
  --headless
```

### 2. 评测与导出
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.play \
  --task pai_ppo \
  --experiment_name baseline \
  --load_run Oct31_00-29-08_v1 \
  --checkpoint -1 \
  --num_envs 64 \
  --headless \
  --rl_device cuda:0 \
  --sim_device cuda:0
```

### 3. sim2sim测评
```bash
conda activate pi_env
export WANDB_MODE=offline
export WANDB_SILENT=true
cd /mini_pi_walk
python -m humanoid.scripts.sim2sim \
  --headless \
  --load_model logs/gru/exported/policies/policy_torch.pt \
  --run_dir logs/gru/Nov08_22-06-57_v2
```

脚本默认依次测评与 `play.py` 相同的 11 组运动指令，每组最长运行 12 秒。结果保存到
`<run_dir>/sim2sim/<时间戳>_seed<seed>/`，其中：

- `episodes.csv`：每组指令的存活时间、终止原因及速度/朝向误差；
- `trajectory.csv`：每个策略步的机身状态、关节状态、动作与力矩；
- `report.txt`：各组指令的可读汇总；
- `metadata.json`：模型路径、测评案例和仿真配置。

省略 `--run_dir` 时，如果策略位于 `logs/<experiment>/exported/policies/`，脚本会把结果写入该实验下最近更新的训练 run。只测部分指令可使用
`--cases stand forward_fast turn_left`，需要保存视频时增加 `--record-video`。
