## 四、遥控操作

### 1.使用官方策略
1. 按下 `LT+RT+start`，机器人站起
2. 按下 `LT+RT+LB`，机器人进入运动状态
3. 通过左摇控提供线速度指令，通过右摇杆提供角速度指令
4. 按下 `LT+RT+LB`，机器人进入静止状态
5. 按下 `LT+RT+RB`，机器人蹲下

### 2.使用自己部署的策略
1. 在确保机器人已经蹲下或挂起时，按下 `LT+RT+B`，机器人进入`PROTECT`
2. 再次按下 `LT+RT+B`，机器人进入`INITIAL`
3. 连续按下两次 `LT + RT + ->`，背板此时显示`CUSTOM`
4. 按下 `LT+RT+B`，选中`CUSTOM`模式
5. 按下 `LT+RT+start`，机器人站起
6. 按下 `LT+RT+LB`，机器人进入运动状态
7. 通过左摇控提供线速度指令，通过右摇杆提供角速度指令
8. 按下 `LT+RT+LB`，机器人进入静止状态
9. 按下 `LT+RT+RB`，机器人蹲下
